# Runner’s HIGH!!!

8인 트랙 육상 육성 웹 프로토타입. 원작의 코드와 에셋을 사용하지 않은 독립 구현입니다.

## 실행

추가 패키지 설치 없이 `python -m http.server 8786 --directory dist` 후 http://localhost:8786 에 접속합니다. 밸런스 시뮬레이션은 Web Worker를 사용하므로 파일 직접 열기 대신 HTTP 서버로 실행하세요.

## 게임

- 400m 트랙, 800/1000/5000/10000m.
- 훈련 5회 완주 시 공식경기 입장. 체력 0이면 DNF.
- 체력·지구력·속도·효율·가속·전술을 코인으로 강화, 레벨 상한 100.
- 수동 가속, 4가지 전략, 공식 완주/입상/기록/잔여 체력 보상.
- 브라우저별 로컬 자동 저장. 계정·기기간 동기화 없음.

## 밸런스 실험실

성장량, 비용, 보상, 체력 소모와 공식 상대 수준을 조절합니다. 실제 저장과 분리하여 새 선수 10/20/50명의 첫 입상까지 반복 계산하거나 원하는 능력치로 단일 경기를 테스트할 수 있습니다. 설정 적용은 이후 경기와 강화에 영향을 줍니다.

첫 입상 목표 50–60분은 4배속·경기 사이 15초·800m·기록 우선 구매·후반 자동 가속이라는 비교 조건의 중앙값 목표이며 강제 시간 잠금이 아닙니다. 실제 플레이에서는 가속을 직접 사용합니다. 결과 미달성은 150경기에서 종료하고 성공 선수 중앙값에서 제외하며 성공률도 함께 표시합니다.

`node test.cjs`로 규칙 검사, `node calibrate.cjs`로 50명 성장 시뮬레이션을 실행합니다. 결과는 `calibration.json`에 기록됩니다.

## 구조

- `dist/engine.js`: UI 없는 결정론적 경기·강화·보상 엔진
- `dist/app.js`: Canvas 경기 화면과 로컬 저장
- `dist/lab.js`, `dist/worker.js`: 실험실 화면과 반복 계산
- `dist/styles.css`: 반응형 디자인

프로토타입의 경기 기록은 게임용 수치이며 실제 선수의 운동 능력을 예측하지 않습니다. 기존 Family Go 참고 프로젝트와 별개입니다.
